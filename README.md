## What I'm Doing

- **Native macOS** — 构建轻量、原生、注重体验的菜单栏与桌面工具。
- **Self-hosted services** — 把图床、统计、邮件、发布与网络工具做成可自己部署的服务。
- **Web & AI tools** — 快速验证新想法，把常用需求做成简单可直接使用的产品。
